## Already implemented (DO NOT redesign; read them before coding)

- `config.py` — `Settings` (pydantic-settings, env vars, no prefix) + `get_settings()`. Add new settings fields only if truly needed, with sensible defaults, and document them in `.env.example`.
- `models.py` — `NewsRecord` (the ONE unified object that flows through every stage), `LLMVerdict`, `AlarmEvent`, `Report`, `Answer`, `Citation`, `Stage`, helpers `canonical_url`, `article_id_for`, `utcnow`.
  - `NewsRecord.new(...)` builds a record; `apply_verdict(verdict, threshold)` applies the alarm policy (score >= threshold → is_alarm, alarm_reason = reason + "LLM Özeti: ..." ; else both empty); `mark_not_scored()` for records that never went to the LLM.
  - `to_message()/from_message()` for the broker; `to_es_document()` for Elasticsearch.
- `broker.py` — `Broker` protocol, `InMemoryBroker` (tests/dev), `RabbitMQBroker` (pika), `Message`, `Reject`, `Retry`, `RoutingKey`, `Queue`, `QUEUE_BINDINGS`, `make_broker(settings, in_memory=...)`.
  - Handler signature: `def handler(msg: Message) -> None`. Return = ack. Raise `Reject` = dead-letter now. Raise anything else (incl. `Retry`) = delayed retry via `<queue>.retry`, dead-letter after `rabbitmq_max_attempts`.
  - `broker.consume(queue, handler, prefetch=None, stop_event=None, max_messages=None) -> int` blocks (InMemoryBroker returns when the queue is empty).
- `textutil.py` — `tr_lower`, `tr_fold`, `normalize_ws`, `html_to_text`, `KeywordMatcher(keywords).find(text) -> list[KeywordHit]`, `.matches(text) -> list[str]`, `excerpt`.

## Data flow (RabbitMQ topic exchange `news.topic`)

```
scraper ──article.raw──▶ q.articles.raw ──▶ keyword filter
   keyword filter: hit        ──article.keyword──▶ q.articles.keyword ──▶ LLM scorer (Ollama) ──article.scored──▶ q.articles.scored
   keyword filter: no hit     ──article.scored (mark_not_scored) ─────────────────────────────────────────────▶ q.articles.scored
alarm layer (consumes q.articles.scored): index EVERY record into ES `news-articles`;
   if is_alarm: AlarmEvent → ES `news-alarms` + sinks (log/webhook/telegram) + ──alarm.raised──▶ q.alarms
reporting layer: consumes q.alarms (alarm digests) + periodic reports from ES → ES `news-reports` + ──report.*──▶ q.reports
API (FastAPI): search, alarms, reports, stats, /ask (RAG over ES + Ollama), dashboard.
```

## Sites (verified 2026-10-02)

Listing `https://www.hurriyet.com.tr/gundem/` has 30 anchors `href="/gundem/<slug>-<id>"`; `?page=N` returns the same page (JS pagination) — do NOT rely on it. - 12punto: the real site is `https://12punto.com.tr` (12punto.com is a parked domain). RSS `https://12punto.com.tr/rss` (20 items, mixed categories) and per-category `https://12punto.com.tr/rss/<category>` (gundem, siyaset, …). RSS links are `http://` → normalize to https. ## Module contracts

### A. `scrapers/` (owner: scraper agent)
- `scrapers/base.py`: `HttpClient(settings)` (requests.Session, UA, timeout, tenacity retry on 5xx/connection errors, per-host politeness delay, `get_text(url) -> str`), `DiscoveredLink(url, title_hint, published_hint, category_hint, rss_html, rss_summary)`, `Source` Protocol: `name: str`, `discover(client, *, backfill_days=0, limit=None) -> list[DiscoveredLink]`, `fetch_article(client, link) -> NewsRecord | None`. Shared helpers: `parse_jsonld_newsarticle(html) -> dict | None` (handles dict, list, @graph), `parse_tr_date(text) -> datetime | None` (ISO, "02.10.2026 22:41", "Ekim 02, 2026 22:34", RFC822; naive → Europe/Istanbul +03:00; result tz-aware), `extract_meta(html) -> dict`.
- `scrapers/hurriyet.py`: `HurriyetSource` (name "hurriyet") — discovery = RSS items + listing anchors, only `/gundem/` URLs; `fetch_article` parses the page; on fetch failure falls back to RSS `<text>` body (html_to_text) + `<abstract>` as subtitle so a record is still produced. Strip boilerplate. `subtitle` = JSON-LD description / spot h2. `published_at` = datePublished (fallback dateTimeWritten/pubDate), `updated_at` = dateModified.
- `scrapers/punto.py`: `PuntoSource` (name "12punto") — discovery = `/rss` + `/rss/<cat>` for all `settings.punto_category_list` + listing pages `/<cat>` + archive search day-by-day when `backfill_days > 0`. Skip non-article URLs (must match `/<slug>/<slug>-<digits>$`). Parse JSON-LD list form.
- `scrapers/state.py`: `SeenStore(path)` SQLite (WAL, thread lock): `status(record_id, content_hash) -> "new" | "updated" | "unchanged"`, `mark(record)`, `count()`, `seen_urls(limit)`.
- `scrapers/runner.py`: `ScrapeRunner(settings, broker, seen_store=None, sources=None)`: `run_once() -> ScrapeStats` (dataclass: per-source discovered/fetched/published/unchanged/errors), `run_forever(stop_event=None)`. Publishes `record.to_message()` with `RoutingKey.ARTICLE_RAW`. Respects `max_articles_per_run`, `request_delay_seconds`. Re-publishes "updated" records (same id, new content_hash). `build_sources(settings) -> list[Source]`.
- Tests: `tests/test_scrapers.py` (offline, fixtures) + `tests/test_live_scrapers.py` (`@pytest.mark.live`).

### B. `pipeline/keyword_filter.py`, `pipeline/llm.py`, `pipeline/prompts.py`, `pipeline/scorer.py` (owner: pipeline agent)
- `KeywordFilterService(settings, broker)`: `.handle(msg: Message)` and `.run(stop_event=None, max_messages=None)` (consumes `Queue.ARTICLES_RAW`). Hit → `matched_keywords`, `stage=Stage.KEYWORD`, publish `RoutingKey.ARTICLE_KEYWORD`. No hit → if `settings.llm_score_all` publish to ARTICLE_KEYWORD with empty matched_keywords else `mark_not_scored()` and publish `RoutingKey.ARTICLE_SCORED`. Invalid message → `Reject`.
- `OllamaClient(settings)`: `chat_json(system, user, *, temperature=None, num_ctx=None, timeout=None) -> dict` (POST `/api/chat`, `format: "json"`, `stream: false`), `generate_text(system, user) -> str`, `embed(texts) -> list[list[float]]` (POST `/api/embed`, fallback `/api/embeddings`), `health() -> bool`, `model_available() -> bool`. Exceptions: `LLMUnavailable` (connection/timeouts/5xx), `LLMBadOutput` (unparseable JSON). `FakeOllama(responder=None, embed_dims=8)` with the same interface for tests; `responder(system, user) -> dict|str`. Also `HeuristicLLM(settings)`: deterministic fallback verdict from keyword counts (used by `--fake-llm` dev mode). Expose a common Protocol `LLM`.
- `ScoringService(settings, broker, llm)`: `.score_record(record) -> NewsRecord` (pure; builds the Turkish analyst prompt, truncates content to `ollama_max_content_chars`, validates into `LLMVerdict`, retries bad output up to 2 times in-process, then raises `Retry`; on `LLMUnavailable` raises `Retry`), `.handle(msg)`, `.run(stop_event=None, max_messages=None)` (consumes `Queue.ARTICLES_KEYWORD`, publishes `RoutingKey.ARTICLE_SCORED`).
- Scoring rubric (in `prompts.py`, Turkish): 0-100. 80-100 critical (presidential/ministerial decisions with wide impact, fund/financial crime investigations, arrests of officials, market-moving policy); 60-79 important; 30-59 noteworthy; 0-29 routine/irrelevant (sports, magazine, PR). JSON schema: `{"alarm_score": int, "is_alarm": bool, "reason": str, "summary": str, "topics": [str], "entities": [str]}`.
- Tests: `tests/test_pipeline.py`.

### C. `store.py`, `pipeline/alarm.py`, `alarm_sinks.py` (owner: store/alarm agent)
- `store.py`: Protocol `ArticleStore`: `ensure_indices()`, `index_record(record, refresh=False)`, `index_alarm(event, refresh=False)`, `index_report(report, refresh=False)`, `get_record(id) -> dict|None`, `get_alarm(alarm_id) -> dict|None`, `search_records(query: str, *, since=None, until=None, sources=None, only_alarms=False, size=20, min_score=None) -> list[SearchHit]` (`SearchHit(doc: dict, score: float)`; recency-boosted BM25 over title^3/subtitle^2/content/llm_summary with Turkish analyzer), `recent_records(since=None, size=50, only_alarms=False)`, `recent_alarms(since=None, size=50)`, `stats(since, until) -> dict` (keys: `total`, `alarms`, `by_source`, `by_keyword`, `by_category`, `avg_alarm_score`, `by_hour` list of {ts, count, alarms}, `top_alarms` list), `list_reports(kind=None, size=20)`, `knn_search(vector, k, since=None)` (optional; returns [] when embeddings disabled), `refresh()`.
  `ElasticsearchStore(settings)` (elasticsearch-py 8): index mappings with `turkish` analyzer, `@timestamp`, keyword fields for id/source/category/matched_keywords/content_url, `embedding: dense_vector(dims=settings.embedding_dims, index=true, similarity=cosine)` only when `settings.ollama_embedding_model` is set (`settings.embedding_dims`, already present). Upserts by `id`. `InMemoryStore()` implements the same Protocol (simple token-overlap scoring + recency) for tests and `--in-memory` dev mode.
- `alarm_sinks.py`: `AlarmSink` Protocol (`name`, `send(event: AlarmEvent) -> None`), `LogSink(path)` (logger + JSONL append), `WebhookSink(url)` (JSON body `{"text": "...", "event": {...}}`), `TelegramSink(token, chat_id)`, `build_sinks(settings) -> list[AlarmSink]`.
- `pipeline/alarm.py`: `AlarmService(settings, broker, store, sinks=None)`: `.handle(msg)`, `.run(stop_event=None, max_messages=None)` consuming `Queue.ARTICLES_SCORED`. For every record: `stage=Stage.ALARM`, `index_record`. If `is_alarm`: build `AlarmEvent.from_record`, set `record.alarm_id/alarmed_at`, re-index record, `index_alarm`, notify sinks (failures logged, never fatal), publish `RoutingKey.ALARM_RAISED` with `event.to_message()`. Idempotent on redelivery (skip notify/publish if the same `alarm_id` already exists in the store with the same `content_hash`).
- Tests: `tests/test_store.py`, `tests/test_alarm.py`.

### D. `reporting/` (owner: reporting agent)
- `reporting/prompts.py` (Turkish prompts: narrative report, query rewriting, RAG answer).
- `reporting/builder.py`: `ReportBuilder(settings, store, llm)`: `build(kind, window_start, window_end, *, narrative=True) -> Report` (stats via `store.stats`, top alarms via `store.recent_alarms`, LLM narrative in Turkish with template fallback when LLM unavailable).
- `reporting/rag.py`: `QAEngine(settings, store, llm)`: `ask(question, *, since_days=None, top_k=None, sources=None) -> Answer`. Steps: query rewrite (LLM JSON `{"search_terms": [...], "entities": [...]}`, fallback = question tokens) → retrieval (`store.search_records` with since; optional `knn_search` with `llm.embed`; reciprocal-rank fusion) → context newest-first with dates/sources → Turkish answer with citation markers [1],[2] and explicit "son durum" ordering; say so when evidence is insufficient. Must work with `FakeOllama`.
- `reporting/service.py`: `ReportingConsumer(settings, broker, store, builder)` consuming `Queue.ALARMS` (collect alarms; emit `alarm_digest` Report every `report_digest_every` alarms or `report_digest_minutes`; both already exist in Settings with defaults 10 / 30), and `PeriodicReporter(settings, store, builder, broker)` with `run_once()` / `run(stop_event)` every `report_interval_minutes` over the last `report_window_hours`. Both `index_report` + publish `RoutingKey.REPORT_GENERATED` / `REPORT_ALARM_DIGEST`.
- `reporting/api.py`: `create_app(settings, store, llm, broker=None) -> FastAPI`. Endpoints: `GET /health`, `GET /articles/search`, `GET /articles/{id}`, `GET /alarms`, `GET /reports`, `POST /reports/generate`, `GET /stats`, `POST /ask` (body `{"question": str, "since_days": int?, "top_k": int?}` → `Answer`), `GET /` HTML dashboard (Jinja2 template in `reporting/templates/dashboard.html`: stats, latest alarms, ask box using fetch to `/ask`).
- Tests: `tests/test_reporting.py` (InMemoryStore + FakeOllama + `fastapi.testclient`).
